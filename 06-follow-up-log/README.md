# Follow-up log

Copy the blank CSV into your private workspace. The example is independently authored fiction. Log one event per row and retain the stable candidate ID. Allowed statuses: Draft, Awaiting reply, Replied, Paused, Closed, Opted out. Record actual human authorization separately from AI suggestions. Set an agreed cadence and maximum attempts; never follow up after an opt-out. Before contact, check the complete history across channels to prevent duplicate outreach. This log is manually maintained and does not affect scoring.
